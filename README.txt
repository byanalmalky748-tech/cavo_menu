CAVO CAFE — مشروع منيو HTML/CSS
================================
الملفات:
- index.html: الصفحة الرئيسية والشعار وأزرار الأقسام
- cold.html: المشروبات الباردة
- hot.html: المشروبات الحارة
- desserts.html: الحلا
- boxes.html: بوكسات Cavo
- daily.html: قهوة اليوم
- style.css: التصميم المتجاوب للجوال والآيباد والابتوب
- assets/cavo-logo.jpg: الشعار المرفق بعد قصه من الصورة

طريقة التشغيل في Visual Studio Code:
1) فكّي ضغط الملف.
2) افتحي مجلد Cavo_Menu_Website في Visual Studio Code.
3) افتحي index.html بالمتصفح، أو استخدمي إضافة Live Server.
4) لتغيير الأصناف والأسعار، افتحي صفحة القسم المطلوبة وعدّلي الاسم والوصف والسعر داخل بطاقة المنتج.
5) لتغيير الألوان، عدّلي المتغيرات في أعلى style.css.

ملاحظة: الأسعار والأصناف الحالية أمثلة تجريبية وليست أسعار المتجر الفعلية.
الموقع HTML وCSS فقط، ولا يحتاج قاعدة بيانات أو PHP.
